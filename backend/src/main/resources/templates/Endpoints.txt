API Endpoints (SilkRoad)

POST   /sessions/create                          | Body: {"password": "...", "duration": "PT10M"}                         | {"success": true, "token": "...", "host": true, "session": {"sessionId", "password", "createdAt", "expiresAt", "userCount", "files"}, "timeLeft": "PT10M"}
POST   /sessions/join                            | Body: {"sessionId": "...", "password": "..."}                        | {"success": true, "token": "...", "host": false, "session": {...}, "timeLeft": "..."}
POST   /sessions/rejoin                          | Header: Authorization: Bearer <jwt>                                  | {"success": true, "token": "...", "host": <bool>, "session": {...}, "timeLeft": "..."}
GET    /sessions/{sessionId}/upload-url          | Params: fileName, contentType | Header: Authorization: Bearer <jwt>  | {"url": "...", "fileKey": "..."}
POST   /sessions/{sessionId}/upload-complete     | Body: {"fileName", "fileKey", "fileSize"} | Header: Bearer <jwt>     | {"filename", "fileType", "fileSize"}
GET    /sessions/{sessionId}/files/{fileName}/download-url | Header: Authorization: Bearer <jwt>                        | {"url": "..."}
GET    /sessions/{sessionId}/files/zip           | Param: password                                                      | ZIP stream
DELETE /sessions/{sessionId}/leave               | Header: Authorization: Bearer <jwt>                                  | 200 OK
DELETE /sessions/{sessionId}/file                | Param: fileName                                                      | 200 OK
DELETE /sessions/{sessionId}                     | Header: Authorization: Bearer <jwt> (host only)                      | 200 OK

WebSocket Endpoint: /ws?token=<jwt>
Subscription Topic: /topic/session/{sessionId}
Events:
  {"type": "USER_JOINED", "sessionId": "...", "payload": "<userCount>"}
  {"type": "USER_LEFT", "sessionId": "...", "payload": "<userCount>"}
  {"type": "FILE_UPLOADED", "sessionId": "...", "payload": "<filename>"}
  {"type": "FILE_DELETED", "sessionId": "...", "payload": "<filename>"}
  "Session {sessionId} has been successfully ended. All associated files have been deleted."
